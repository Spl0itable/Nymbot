Full

Nymbot is an anonymous AI assistant built on Nostr, an open protocol nobody owns. There is no sign-up: a keypair is generated on the device, or an existing Nostr key is brought in, and that key is the identity, the conversation history and the credit balance. Every message is end-to-end encrypted as a gift-wrapped Nostr event, with an ML-KEM layer alongside the classical exchange so that traffic recorded today survives a future quantum computer. Replies are paid for in Bitcoin over Lightning, a message at a time, with ten free replies a day and no subscription; in anonymous mode the conversation moves onto a throwaway key and the credits move with it as blind vouchers, so the service can bill a message without learning whose it is. It routes across the frontier models, works inside a connected git repository, and runs as a web app and as native Android and iOS apps. The five things worth knowing

  • There is no account. No email, no phone number, no password. A keypair is generated on the device the first time it opens, and that key is the identity, the history and the balance; sign in with the same key somewhere else and everything is already there. See Identity and login.
  • It can stop knowing who is asking. Encryption was never the gap — attribution was. Anonymous mode moves the conversation onto a throwaway key and moves credits across as blind vouchers the server signs without being able to read, so it charges a message it cannot attribute to a nym. See Anonymous mode.
  • Replies are bought in Bitcoin, one at a time. Ten a day are free. After that a standard reply is ten sats and a pinned frontier model is metered on the tokens it actually reads and writes. There is no subscription, no card and no invoice with a name on it. See Credits and pricing.
  • The encryption is already post-quantum. An ML-KEM key encapsulation runs alongside the classical exchange rather than replacing it, so an attacker has to break both, and traffic captured today is not readable by a future quantum computer. See Encryption.
  • It works in your repository. With a Pro model pinned, Nymbot reads and, with writes on, changes files in a connected GitHub, GitLab or Gitea/Forgejo repository. The access token stays on the device and the listing request goes straight from the device to the forge. See Working in a git repository.

What we do not claim

These belong in an accurate story as much as the rest:

  • The assistant reads your question. End-to-end encryption means nobody else can — it cannot mean the assistant answers something it never saw. Anonymous mode answers the different question of whether it should know who asked.
  • Anonymous mode does not hide an IP address. It breaks the link between a payment and a nym, not the link between a device and a network. Use Tor or a VPN if that is in your threat model, and read what it does not hide before writing that it does.
  • Not every model runs on our own infrastructure. Models badged as hosted do; the rest are proxied to the provider that runs them, which is where a question sent to one goes.
  • There is no published third-party security audit. What Nymbot offers instead is open source apps and a protocol page written against them, so the client can be checked rather than trusted.
  • iOS is not in the App Store. The iOS app builds from source today; Android is on Google Play and Zapstore.
  • Scheduled prompts are not a server. A scheduled run happens in the app while it is open, and one that came due while the app was shut fires when you come back.

Referring to Nymbot

Spell and capitalize the marks exactly as they are written above. Use them as adjectives, not as nouns or verbs, and never in a way that suggests a generic or descriptive meaning.

  • "Ask the Nymbot assistant."
  • "Buy credits in the Nymbot app."
  • "Send a Nymbot."
  • "Nymbot it and see."

Using the wordmark

Use the official wordmark from this page. Do not alter it in any way other than scaling it proportionally.

Clear space

Keep a clear space around the wordmark of at least half its height on every side. Nothing else — text, borders, other logos — belongs inside it.

Minimum size

The wordmark and the icon are built out of small glyphs, and below a certain size they stop being legible and start being noise. Never render the app icon smaller than 48 px, and never render the wordmark narrower than 240 px.

Typography

Nymbot is a terminal by inheritance, and the type follows from that.

  • Monospace — Courier New, Consolas, Monaco. The wordmark, headings, labels and anything that should read as a terminal.
  • Sans-serif — the platform UI stack: SF Pro Display, Inter, Segoe UI, system-ui. Body copy and interface text.

The mobile apps bundle Roboto for the interface and Noto Sans as a broad fallback, so glyphs the primary face lacks still render rather than turning into empty boxes. Color emoji are left to the operating system's own font.
